# 🏡 ATITHI

A full-stack accommodation listing platform inspired by Airbnb, built with the MERN ecosystem. Users can browse, create, edit, and manage property listings through a clean and responsive interface.

---

## 🚀 Features

- Create, view, edit, and delete listings
- Responsive user interface
- Server-side validation using Joi
- Database validation using Mongoose
- RESTful routing
- Error handling with custom middleware
- Bootstrap-based form validation

---

## ⚙️ Installation

```bash
git clone https://github.com/your-username/ATITHI.git

cd ATITHI

npm install

npm start
```

Open your browser and visit:

```
http://localhost:8080
```
